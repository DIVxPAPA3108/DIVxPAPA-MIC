# 💀 DIVxPAPA UNIVERSAL MIC PRO MAX

**DIVxPAPA 💀** makes your microphone sound better on browser calls.

Works on: Telegram Web, WhatsApp Web, Instagram, Google Meet, Zoom Web, Discord — any HTTPS site with WebRTC.

---

## 🚀 Quick Install

1. Go to `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select this folder
5. Open a call site and reload
6. Click the extension icon → check "ACTIVE"

---

## 🎛️ Presets

| Preset | Best for |
|---|---|
| 🌀 **Clear** | Everyday calls |
| 💀 **Max** | Need extra volume |
| 🎛️ **Studio** | Reverb + EQ polish |
| 🛡️ **Safe** | Stable, no clipping |

---

## ⌨️ Shortcuts

| Keys | Action |
|---|---|
| `Ctrl/Cmd + Shift + M` | Toggle on/off |
| `Ctrl/Cmd + Shift + 1` | Clear preset |
| `Ctrl/Cmd + Shift + 2` | Max preset |
| `Ctrl/Cmd + Shift + 3` | Studio preset |

---

## 💬 Commands

Type these in the popup:

```

/clear    /max     /studio   /safe
/mute     /unmute  /reset    /status
/open     /photo

```

---

## 🔒 Privacy

- **No remote requests**
- **No webhooks**
- **No token reads**
- **No session reads**
- **Audio stays in your browser**

---

## 📁 Files

```

manifest.json          — Extension config
background.js          — Service worker
content/loader.js      — Injects script
content/service.js     — Syncs settings
content/injector.js    — Audio processing
popup/popup.html       — UI
popup/popup.js         — UI logic
popup/popup.css        — Styles
core/processor.js      — Audio worklet
assets/icons/          — Extension icons

```

- Works on **browser version** of services only (not native apps)
- Volume slider affects **this device only**
- Voice lock protects **your local mic** only
